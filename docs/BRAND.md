# Pheonix brand

Two marks, two jobs:

- **App mark = the globe**, identical in 2D and 3D: a faint gradient sphere with a lat/long grid (a meridian every 60 deg,
  parallels at 0 and +-45 deg), 0.42 rad axial tilt and a tilted comet-tail orbit ring, in the flame gradient
  `#ffb347`, `#ff7a1a`, `#e8452c` (light to dark). `src/brand/globe` renders it live; `scripts/brand/svg/globeArt.js`
  projects the same geometry to SVG for the favicon, app icons, wordmark and OG image.
- **The phoenix = the character.** A real 3D Three.js phoenix, shown only on the startup splash and in the expanded brand view.

## Palette
`--px-orange #ff7a1a`, `--px-amber #ffb347`, `--px-gold #ffd166`, `--px-red #e8452c`, ink `#0a0809`, text `#fff4e8`.

## Assets (`public/brand/`, generated by `npm run brand`, do not hand-edit)
Globe (the app mark): `globe.svg` (primary), `globe-mono.svg` (single colour, black), `favicon.svg` (the same globe, bolder strokes + denser fill and no parallels so it stays legible at 16px) + `favicon-16/32/48.png` + `favicon.ico` (also copied to `public/favicon.ico`, served at the site root), `wordmark.svg` (globe + font-independent
monoline "Pheonix"; letters are stroke paths, `WORDMARK` in `src/brand/wordmark/letters.js`), `apple-touch-icon.png` (180), `icon-192.png`,
`icon-512.png`, `globe-transparent.png` (1024), `icon-maskable-512.png`, `og-image.svg/png`, `site.webmanifest`, `preview.html` (contact sheet).

**Backgrounds:** every favicon/icon/transparent PNG (favicon.svg, favicon-*.png, favicon.ico, apple-touch-icon, icon-192/512,
globe-transparent, phoenix-transparent) is the object on a fully transparent canvas. The only solid backgrounds are
`icon-maskable-512.png` (platforms require a full-bleed safe zone) and `og-image` (dark card).

Phoenix 2D (kept as the no-WebGL fallback in the splash and for press use): `phoenix.svg`, `phoenix-mono.svg`, `phoenix-transparent.png`,
generated from `src/brand/flat`. The globe artwork lives in `scripts/brand/svg` (`globeProjection.js` for the maths,
`globeArt.js` for the strokes and the swoosh).

The generator is `scripts/brand/build.mjs` (run by `npm run brand`). `svg/` builds the SVG strings (globe, wordmark, OG card,
flat phoenix), `render/` turns them into PNG and ICO with sharp, `manifest.js` writes the web manifest, `paths.js` holds the
output folder. `public/brand/preview.html` is a hand-written contact sheet, not generated.

Icon `<link>` hrefs and manifest icon srcs carry `?v=3` (bump it when the artwork changes) because browsers cache tab icons hard.

## Runtime
```js
import './brand/brand.css';
import { showSplash, createBrandView } from './brand/splash.js';
import { createGlobeMark } from './brand/globeMark.js';
// or, from the module index: import { showSplash, createBrandView, createGlobeMark, createPhoenixLogo } from './brand/index.js';

const splash = showSplash(document.getElementById('splash'));
splash.ready(globeReadyPromise);
await splash.dismiss();            // min ~1.7s, max wait 7s, fades, disposes the 3D phoenix
const brand = createBrandView(document.body); brand.open();  // no close button: click/tap anywhere or Esc closes it

const mark = createGlobeMark(el, { size: 60 });   // top-left app mark; mark.start() / stop() / dispose()
mark.start();
```

### `createPhoenixLogo(el, { size, reducedMotion, onReady })` returns `{ start, stop, render(t?), resize, dispose, failed }`
Lives in `src/brand/phoenix/`. The bird is procedural geometry merged into one mesh (about 80k triangles, 1 draw call):
a sculpted S-neck body and smooth eyeless head with a hooked beak, a crest and nape plumes, small shingled body feathers,
talons, two wings of about 65 individually curved, twisted and cupped feather blades with real 3D rachis tubes in layered
rows (tertials, secondaries, primaries, three covert rows, flame fringe), and a tail of 7 ribbon feathers with eyespots plus
4 long streamers. The shader does key, rim and fill lighting, fresnel rim, back-light translucency, procedural barbs and
notched feather edges (alpha to coverage), and a flame flicker travelling up each feather. Animation: slow cinematic orbit,
gentle wing beat and fold, breathing, tail waves, ember particles. A small custom bloom (scene, bright pass, separable blur
at 1/2 and 1/4 res, composite) and an aura sprite give the glow. The canvas background is transparent.

Folders: `model/` (geometry: `feather`, `tube`, `body`, `head`, `wing`, `tail`, `legs`, merged in `index.js`), `shaders/`
(GLSL strings), `stage/` (bird mesh, aura, embers, canvas and renderer, viewport framing), `post/bloom.js`,
`animation/pose.js` (the pose for a given time), and `index.js` (`createPhoenixLogo`). `phoenix.css` styles the host box.

It owns its WebGL context, stops its rAF on `stop()`, hidden tab or offscreen, renders one static 3/4-view frame under
reduced motion (no embers), disposes geometry, materials, render targets and the renderer, and the splash falls back to the
2D `phoenix.svg` if WebGL is unavailable (`failed === true`). `render(t)` draws a deterministic frame at time `t` seconds.

### `createGlobeMark(el, { size = 60, reducedMotion })` returns `{ start, stop, dispose, render(t?), failed }`
Lives in `src/brand/globe/` (`shaders/`, `sphere.js`, `orbit.js`, `scene.js`, `fallback.js`, `index.js`). The live version of
the app mark: faint gradient solid sphere, anti-aliased lat/long lines drawn in the fragment shader (crisp at ~56px), the far
hemisphere dimly visible, a tilted comet-tail orbit with a spark riding it, gentle spin. Transparent background, one small
renderer, stops when hidden or offscreen, one static frame under reduced motion. If WebGL is unavailable it shows
`globe.svg` instead (`failed === true`).

### Splash and brand view
`src/brand/splash/`: `showSplash`, `createBrandView`, the inline wordmark SVG and the logo mount with its no-WebGL fallback.

### Layout of `src/brand/`
`phoenix/`, `globe/`, `splash/` (the three features), `flat/` (2D phoenix data used by the asset script), `wordmark/`
(font-free letter paths), `shared/` (asset URLs, reduced-motion check, rAF scheduler, shared overlay and reduced-motion CSS),
`index.js` (public API) and `brand.css` (imports every component stylesheet; order matters). The app imports `phoenix3d.js`,
`globeMark.js` and `splash.js` lazily, and those three files are thin re-exports of the folders above.

## Changing the design
Phoenix: edit `src/brand/phoenix/model` (feather rows are plain parameter tables in `wing.js`, `tail.js` and `head.js`).
Flat phoenix: edit `src/brand/flat` (parameter tables in `featherTables.js`), then run `npm run brand`.
Globe: edit `src/brand/globe` for the live mark and `scripts/brand/svg` for the flat art, then run `npm run brand`.
